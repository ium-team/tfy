# TFY 0.1.1 Beta Notes

This beta is the first forward release line using TFY's beta/stable maturity model. Beta means the build is publicly testable and installable for development/dogfooding, while stable remains the completed default install channel after evidence gates pass.

## Highlights

## Install

```sh
npm install -g @ium/tfy-cli@beta
tfy start --agent
# or
tfy start --human
```

Stable installs use `npm install -g @ium/tfy-cli` only after a reviewed stable release exists on npm `latest`.
