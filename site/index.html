What TFY does

A representation ladder for the whole AI coding loop.

Tool Gateway Commands become compact, recoverable model text only when that is safer and smaller.
Context Gateway Project context can move through summaries, skeletons, selected detail, or full fallback.
Output Gateway Agent output can be previewed, restored, and validated before project-ready edits.
State Gateway Long-running task state can become a compact ledger with refs back to evidence.

Why it stays honest

TFY is not a lossy summarizer with a cool name.

The model-facing default is plain text plus local refs. JSON surfaces are explicit debug, adapter, or internal contracts, not the default payload.

  • Raw evidence first. Store exact stdout/stderr before reducing anything.
  • No negative savings. Show compact output only when it beats redacted raw output.
  • Fallback is success. Expand when diagnostics, uncertainty, or risk demands it.
  • Agent-neutral core. Keep the protocol usable by ordinary tools and runtimes.
